Built a dual-toolhead/toolchanger 3D printer stack running Klipper firmware on an STM32H723 controller.

**Mechanical & Electrical:** Designed and configured tool docks, offsets, and calibration workflows. Tuned TMC5160 stepper drivers over SPI and calibrated motion limits and endstops using log-driven diagnostics.

**Firmware/Macros:** Authored Klipper macros for tool selection, safe homing sequences, and BLTouch automatic bed leveling routines. Calibrated tool offsets and verified repeatability across many tool swaps.

**Skills:** Klipper/3D printer firmware, STM32, TMC stepper drivers, SPI, motion calibration.
