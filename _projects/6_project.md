Built a 3D-printed fingertip haptic interface integrated with a virtual simulation environment for tactile force feedback.

**Software:** Integrated OpenHaptics and CHAI3D to construct a virtual environment with tunable stiffness and force-feedback parameters. Communicated with the physical microcontroller-based manipulator over a serial link.

**Hardware:** The fingertip device is 3D-printed and driven by a microcontroller that receives setpoints from the host simulation and returns position/force sensor data in real time.

**Skills:** OpenHaptics, CHAI3D, C++, serial communication, force-feedback control, 3D printing.
